# Matched American-put visualization export

Regime: `put_T100_s060_r005_q010`. This compact package contains direct pointwise Arm C/D seed-101 predictions and the stored high-accuracy reference on a common plotting grid. No model was retrained, no held-out score was rerun, and neural values were not clipped or projected to the payoff.

The source artifacts remain outside Git. `validation_report.json` records finite-array, coordinate, tau=1 slice, payoff, boundary, and independent reference-equivalence checks.
