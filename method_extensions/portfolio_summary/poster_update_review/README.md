## Important limitation

This is an artifact and claim audit, not a complete rerun of every member's experiment. A numerical claim is called poster-ready only when the repository contains enough configuration, scope, metrics, and caveats to state it accurately. Results from different protocols are not treated as a direct head-to-head comparison.
